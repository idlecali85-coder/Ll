# Secret Number Game

A beginner JavaScript guessing game.

## How to play
1. Open `index.html` in a web browser.
2. Click **Start Game**.
3. Guess the secret number (15).
4. You have up to five attempts.

## Concepts used
- Variables (`const` and `let`)
- `while` loop
- `prompt()` and `alert()`
- `if`, `else if`, and `else`
- Converting input to a number with `Number()`

## GitHub submission
Create a repository named `javascript-secret-number-game`, then upload `index.html` and `README.md`. Follow your instructor's Google Classroom instructions for submitting the repository link.
